# 项目现状与迁移边界

2026 年 10 月 16 日核查后决定采用独立新主线，旧版本冻结为参考。新版本先完成 Pi CLI 真实攻防，再扩展 D2Guard 能力，最后实现 Web 与 Electron 展示。

## 旧版现状

旧版 207 项 pytest 通过，TypeScript 与 Vite 构建通过。但独立进程探针发现：没有模型时 PB01 的 live 路径仍在 3.73 秒内外发 25 字节；pytest 标志改变同一路径；安全完成的模型环结果也被追加回放覆盖。开启防护可阻断这条预设外发。因此旧内核有工作基础，旧 live 统计不代表真实模型攻防。

最新源码修改于 10 月 16 日上午，原 Windows 包生成于 10 月 15 日晚。公网入口核查时连接关闭，线上版本未确认。旧工作区无 Git 元数据，历史提交对应关系未确认。

## 当前可用环境

- Windows 本机 Node 24.15.0，Pi 0.85.1 已安装。
- 沿用旧版用户配置的模型接口，认证信息仅从本地配置读取；模型列表接口已连通。
- 当前无已确认可用的 Docker 或 WSL Linux 发行版。旧运维信息中的公网及局域网 SSH 接入均返回公钥认证失败。
- 首轮使用限制文件范围和网络目标的实验工具，禁止任意 Shell。完整命令执行及 OS 级隔离属于后续独立验收项。

## 归档与复用

旧源码参考 ZIP 与逐文件清单位于 `../../archive/2026-10-16-legacy/`，原文件、发行包和运行数据保留原位。新版本不导入旧 Agent 运行器、回放控制器或成功率数据。归一化、账本、审批与策略仅为候选复用组件。
