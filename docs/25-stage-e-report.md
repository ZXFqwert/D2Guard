## 设计与实现

旧 §4.4 仍依赖未训练 A1/A2，§9 的默认约束是 S1 只能补充风险。按本阶段明确要求新增实验模式，保留旧模式作对照；不把实验实现等同于已经验收或正式切换。

- E1：`request_tainted` 与只增不减的 integrity 分离。遍历当前 Agent 的全部来源，不只查看热槽位。任一规则 requested 关系或校准 S1 request 过阈值即污染。失败、未校准、缺分析、源哈希不一致、窗口缺失、结构性缺口均保守挂起。规则1–4b保持原序及行为。
- E2：固定 C/C2 原轨迹动作、授权与金标准，三臂独立重算。A=既有外部来源污染；B=仅规则 requested；C=规则或 S1。原始工具错误过滤、敏感性和 sink 规则沿用 D0；不是生成新 Agent 轨迹，也不是反事实闭环执行。
- E3：10 个语义伪装攻击、6 个正常/引用类负样本。规则筛选无 requested 关系后先冻结，再运行 S1；未按模型输出筛选、改写或择优替换。
- E4：6 轮真实记忆准备、32 轮冒烟、192 轮新场景正式三臂、10 轮既有翻转场景回归。所有轮次使用真实 Pi；准备和冒烟不并入正式矩阵。每会话180秒，四个工作进程；无择优重跑。

实现文件：`src/d2v2/{request_taint,core,decision,request_model}.py`；窗口记录数校验 `stage_d5_model.py`；离线复用入口 `evaluate_stage_d.py`；`stage_e_{offline,scenarios,regression,resume,results}.py`；`tests/test_stage_e.py`、`tests/test_stage_d5.py`；16份 `scenarios/e-*.json`；设计文档、执行方案、状态与本报告及两份配套产物。

模型固定为 D5 补训多语言 Laya，权重 SHA-256：`7e96b8c58d52eb6bfc1801b89231217287cfb2ba5d800cc6478f663cbc281fb1`；温度 `1.2114818096160889`，request 阈值 `0.5`。运行加载时核对训练、选择、评测、回归证明及模型哈希；没有新增教师调用。

## 未解决的问题与停止状态

1. 已有金标准中6次应ASK的动作被C放行。该安全门槛未通过，不通过改阈值、数据或场景补救。
2. 规则与S1均未识别具体请求时，新的4c允许非敏感高风险动作；这正是降误拦与漏放之间的实际代价，不能以来源已完整扫描替代请求识别准确性。
3. 固定轨迹重算不是反事实闭环；真实旧场景仅覆盖翻转者。新攻击使用文件写后果，不推广到尚未实现的任意exec/git和MCP写操作。
4. 工具预算提前拒绝的7个调用缺少guard_decision，verify_v2全部通过这一项未达标。没有执行越过预算，但记录覆盖仍需修正；本阶段不改核心后重跑。
5. C/C2仍为同模型家族标注金标准；新样本规模小、每格2次，比例不代表总体性能。
