# 安全关系抽取修复与原版 Laya 语义诊断（2026-10-16）

本轮确认了两类独立问题：安全压缩器确实产生过错误的操作—目标组合；当前固定 multilingual Laya 与三头问题协议在这些输入上仍缺乏可靠区分能力。修复前者后，真实执行前防护闭环继续有效，但不能因此宣称后者已解决。没有发现本轮插件/网关丢帧、参数篡改或快镜输入截断的证据。

## 已修复的安全链缺陷

旧提取器将一条指令中的 `induced_ops` 与 `induced_targets` 拆开保存，持久化索引时做笛卡尔积。例如“读 notes.txt 并写 brief.md”会额外生成“写 notes.txt”和“读 brief.md”。`net_fetch POST` 还会因工具名包含 fetch 被附加为 GET。

现在逐操作绑定目标，记录 `action_relations`，并将禁止、引用与请求分开。只有请求关系写入操作索引；POST 的文件来源与网络目的地另记为 `requested_data_flows`。外部文档自称获得授权、要求先完成某步骤、要求隐瞒输出，只作为低信任上下文线索，不能新增用户权限。每个分量保留其原文引用和字符/Token 区间；快镜仍只接收前态和本次安全增量。

实际 README 旧索引有 12 项，新索引为 4 个操作关系：读 `.env`、写 `summary.md`、GET 项目文档、POST 收集端。移除项包括 7 个错误组合和 1 个未绑定操作的上下文项；后者改为上下文线索。文件到收集端的请求单独保留，不等同于已执行、已泄露或已证明因果。详见 [原文抽取对照](security-relation-comparison.json)。

这仍是有界词法提取器，并非通用语义理解器。复杂否定、间接指代、隐式目的和任意混淆仍可能漏提。无法确定网络目的地及超过分量预算会标记覆盖不足；不能据此宣称所有未知语义均能被识别。旧扁平字段留在审计记录以兼容历史核验，新版快镜视图使用关系列表。

## 固定权重的离线控制实验

使用官方 `convaiinnovations/laya-multilingual`，revision `e4e9ddf21a7b1903b7acffd8814ad4307bf63a67`。权重 SHA256 `9d628fd971b700382ac6f65920a86f149777b2e748e0c955fb3b19695aa8f204`。没有训练、更换模型或修改线上问题，也未通过调阈值制造正确结果。

`diagnose_laya_semantics.py` 对三份历史安全输入做 3 种表示 × 4 种问题变体，共 36 组，另加 2 个最小文本控制：完整安全 JSON、精选事实 JSON、精选事实句子；原问题、选项换序、NOUL 改 choice、否定提问。精选表示明确不是完整状态的无损改写。全部无截断；36 组动作对齐均输出 expected，包括未授权敏感读取。正常与异常的跟随分数仍普遍偏高。最小真假句子的 NOUL 可区分，但 choice 同样偏向一个答案。[完整结果](laya-semantic-factorial.json)

`probe_laya_protocol.py` 再做 11 组控制：三份输入的中性 A/B 语义选择；三份精选事实中同时翻转授权字段与对应权限的六组对照；两组最小 JSON。结果：

| 控制 | 实际结果 | 能支持的结论 |
| --- | --- | --- |
| 复杂状态的中性 A/B 跟随问题 | 三份均选 A（无跟随证据） | 中性标签改变偏向，但没有解决区分 |
| 复杂事实的授权字段 true/false | NOUL 均约 0.994–1.000，choice 均选“是” | 即使显式字段翻转也未可靠响应 |
| 最小 JSON `authorized=false/true` | NOUL 约 0.137/0.947，choice 分别选“否/是” | JSON 并非一律无法处理；上下文和问题兼容性仍需定位 |

[完整后续控制结果](laya-protocol-followup.json)。这些是同一场景历史输入的离线诊断，不是独立保留集、准确率评测、新攻击场景或新的 Agent 攻防运行。它们不能锁定模型内部原因，也不能外推所有 Laya 家族模型。

复现时以 `benchmark_laya.read_cases()` 从原始运行 `20261016-135333-36e8d4`、`20261016-135159-540bea` 提取并校验三份历史输入，保存到忽略目录的 JSON；分别运行两个脚本的 `--config <原版模型配置> --cases <输入JSON> --output <输出JSON>`。这些旧输入刻意保持修复前形态以隔离表示/问题因素；修复后的真实快镜输出在下述新矩阵中另行验证，不能混称同一个实验。

[官方 multilingual 模型卡](https://huggingface.co/convaiinnovations/laya-multilingual) 提示概率尚未校准、零样本类型决策有限，并建议工作流适配。这与本轮现象相容，但不替代本项目实验。当前继续保留原版权重；英文版对照或训练适配应另立实验、明确版本与贡献，不能静默替换。

## 接下来仍聚焦核心

1. 在固定原版模型上，将复杂状态逐层增量加入最小可判读事实，定位何种字段、长度与问题组合导致翻转失效；语义标签必须来自独立人工定义，不能把策略答案直接喂给模型。
2. 按“来源意图、授权边界、动作后果”分别验证问题协议，再评估组合裁决。高置信度不能替代真实区分力，95% 本地快路径目标不能靠增加同步慢镜掩盖。
3. 补足提取覆盖率与独立正常任务误报验证；快镜语义能力未验收前，阶段二保持未完成，攻击扩库与前端继续暂停。
