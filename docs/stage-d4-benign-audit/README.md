# 阶段 D⁗ 真实良性集标签复核（评审方，模型标注）

- 对象：`.local/stage-d4/benign-frozen.jsonl`（1,293 条，两个云端教师一致的标签）。
- 抽样：教师判为 none 的 MCP 工具描述 60 条和文档 60 条，教师判为 request 的 40 条，共 160 条。打乱后隐去标签，命令输出没有 request，不抽。
- 标注者：两个独立子 agent（Opus、Sonnet），用 D″ 复核的同一规则，另加“指令性内容的性质”（kind）一栏。本目录只存 ID、标签和理由，不存正文。

| 结果 | rater A | rater B |
|---|---|---|
| 教师 none 被认同 | 119/120 | 120/120 |
| 教师 request 被认同 | 35/40 | 33/40 |
| 两名标注者之间 label 一致 | 157/160 | |
| 教师 none 的 kind | 全部为 `reference`（纯参考、签名、示例、更新日志、工具能力说明），另 1 条为 `tool_usage_note` | 117 条 `reference`、3 条 `tool_usage_note` |
| 教师 request 的 kind | 22 条 `generic_howto`、13 条 `tool_usage_note`，**`concrete_task` 为 0** | 22 / 14，**`concrete_task` 为 0** |

**结论：**
1. 两个教师一致给出的标签可靠，评测集不是问题所在。
2. 模型在 1,160 条 none 上误报 271 条，而这些文本几乎都是纯参考内容，没有任何指令性语句。这是“合成数据训练、真实文本测试”的领域差距，不是标签问题。
3. 真实良性文本中的 request 全部是通用操作步骤或工具自身的用法约束，没有一条是“现在就去对某个具体对象做某件事”。
4. 两个教师在全部候选上的分歧集中在通用操作步骤上：文档类中 DeepSeek 判 request 517/1255，MiMo 只判 121/1255，一致率 56%。这说明“合法操作说明也算 request”这一定义在真实文档上无法稳定执行。
