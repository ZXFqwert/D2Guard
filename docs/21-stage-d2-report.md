## 开工方案与现有代码冲突

以下方案在数据生成和训练前登记；两项方法冲突由用户授权我决定。

1. **D″0 独立诊断。** 固定旧模型、旧数据、三类映射和诊断配置；英文 D′ 已发布模型与多语言 epoch 2 检查点各跑一次；旧四类概率按 request=to_agent+for_reader、quoted=quoted、none=data 合并，不用金标准拟合阈值。旧数据字符 3–5 gram TF-IDF＋逻辑回归固定 seed、C=1、最多 1000 次求解迭代，分别评估验证/保留/金标准。云端教师经许可与纯合成冒烟后各做一次资格测试，Gemma4 作参照。开发侧仅查看聚合指标，不查看金标准错误片段。
2. **D″1–D″3 数据。** DeepSeek 逐条生成训练与验证文档；两个教师只见正文、来源和必要的合成上下文，独立复核，不见生成意图、分组、另一教师答案。三方一致才准入。记录原始生成语料为数据产物；请求日志严格只含模型名、耗时、token 数，不存提示词、响应正文、URL、认证信息或异常正文。
3. **D″3b 独立语义保留。** MiMo使用另一套领域/写作简报生成至少 600 条准入样本；另加获准使用的公开测试部分，分别报告两部分与合并指标。冻结后仅返回聚合指标；不把保留集错例交给生成器，不改保留集、不用它校准。
4. **D″4 每轮训练。** 英文 Laya、多语言 Laya 各一组超参数，另做普通 ModernBERT-large 分类头同数据对照；早停只结束本次拟合，恢复最佳验证 loss epoch，继续验证校准与评测。记录每 epoch loss、实际 optimizer 更新及 AMP 跳步数。最多三轮，每轮新增输出目录，原版和失败对照不覆盖。
5. **D″5 迭代与最终冻结。** 每轮只从验证错例提出改进，语义保留集只判断是否达线。模型选择规则须在第一轮前固定，仅使用验证集；保留集不用于候选排序。所有轮次结束后，选定模型及其校准配置，再解锁一次 C/C2 冻结评测。D″0 诊断属于用户明确要求的前置独立测试，不算对新候选反复测试。原版、底座对照、现成分类器、教师一起按冻结协议报告；教师可复用 D″0 中同提示词、同输入的概率结果，提示词如经验证集修订则只在最终统一评测时使用新版。
6. **启用与回归。** 只有全部验收通过才将 S1 request 接入新增风险路径。不得删除任何规则 unknowns/directives。随后只跑 A/B 四格及预先确定的 C2 子集；新增或改变的场景按效率规则先冒烟。未达标保持旁路，并结束本阶段。

现有代码仍是四类受众标签；需新建三类数据/训练/评测模块，保留旧模块和 D′ 检查点用于诊断。旧训练脚本会在过拟合时中止整个流水线；D″ 必须改成恢复最佳 epoch 后继续校准和评测。不会在本次开工核查中提前启用 S1。

用户已授权自行确定的方法口径（在实验前固定）：

- 训练前首句探针验证准确率 ≥90% 即阻止训练。完整字符 n-gram 与微调模型差距采用验证 request F1：训练后微调 F1 必须高出至少 0.03，否则该轮不通过，只能按验证集改进数据。这样解决“未训练模型无法预先比较”的依赖。
- 公开基准允许发送许可准许且排除真实凭据、个人敏感信息的文本进行双教师复核；本仓库源码和真实凭据不外发。

## 指标口径

request 的召回、精确率、F1 和 none 误报率使用验证集拟合后的 request 概率阈值；三类准确率与 macro-F1 使用概率 argmax，macro 只计真值中实际出现的类。因此三类 F1 的 request 分项可能不同于主指标 F1，不能混用。ECE 主报 request 二分类的十等宽概率桶，另在机读文件保留多类 ECE。每轮公开测试、独立生成语义部分和两者合并分别报告；预登记验收要求独立语义和合并部分同时达线。
