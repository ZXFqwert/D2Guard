# 新蓝图执行与阶段二验收（2026-10-16）

已经把新蓝图落成独立 `d2v2` 引擎，并完成真实 Pi 对照。原 `d2core` 保留复现历史。当前通过的是这条攻击的执行前控制与证据链闭环，不是全部检测精度、性能和企业部署验收。

## 已修订的设计矛盾

- 固定 1 KB 与“保存全部异常步”不能同时满足。热视图限制 8 个风险项、8 个近期步；完整证据、授权版本、风险目标索引、指纹、调用阶段和图关系落 SQLite。淘汰热条目后仍可查询历史目标，不能靠挤出风险来保持体积。
- Laya 概率未经过本领域校准，不能把高置信度当安全证明；实测延迟替换示例 `<5ms`。没有修改官方权重或回退旧词袋网络。
- 证据不全、事件缺帧、参数/主体不一致优先于放行。目标已授权不等于所有文件内容都安全；当前普通文档写入覆盖有限，通用代码内容语义检查仍需补齐。
- 无防护网关按原始请求字节透传；仅开启防护时才掩码已登记凭据。网关不重建全部历史安全链，但 DLP 扫描成本仍随完整请求体增长。
- 关联候选、模型支持的关联与客观因果分开。慢镜只引用已存在的证据，不能生成任意跨度，也不能解锁 ASK。
- ALLOW、进入工具执行、失败/未知、确认接收分账。独立 collector 回执才是本实验的真实外发证明。

完整修订保留于 `architecture-blueprint.md`，根目录用户蓝图也已同步修改。

## 已实现

| 部件 | 当前行为与验真入口 |
|---|---|
| Pi Hook | 系统帧、用户帧、助手公开文本与候选调用、工具前裁决、实际进入执行、成功/失败结果、父子 Agent 关联；不采集私有思维链用于安全研判 |
| EvidenceStore | SQLite 追加写和禁止更新/删除触发器，原文 SHA256、事件 ID、字符范围；JSONL 为导出，SQLite 为唯一权威数据源。属于应用层不可变存储，不宣称抵抗管理员改盘 |
| 压缩器 | 独立规则提取授权目标、指令动词/目标、来源信任、敏感指纹与动作事实；不再先用旧快镜标签生成压缩结果。规则覆盖有明确限制，不等于任意自然语言无损理解 |
| 状态链 | 有界热视图与持久化风险索引分离；用户版本化授权不可由外部文件/子 Agent 新增；实际待审动作不会预先混进历史滑窗 |
| 原版 Laya | 官方 `convaiinnovations/laya-multilingual`，固定 revision `e4e9ddf21a7b1903b7acffd8814ad4307bf63a67`；仅输入安全状态与安全增量；三组输出、概率、截断与输入哈希真实记录 |
| 本地裁决 | 五条 YAML 硬策略及既有 Shell AST 分析复用；执行前 ALLOW/ASK/BLOCK。L0 命中独立标注，不能冒充模型检出；exec/git 当前只做离线策略测试，未开放执行能力 |
| 输出融合 | 未授权高风险目标既有关联来源，又出现 expected 与 taint_followed 冲突时，返回 ASK；该阈值只增加审慎控制，不作为安全放行依据。确定性敏感授权边界仍保底 |
| 慢镜 | 按哈希引用回查用户任务、来源片段和动作原文，先脱敏再异步送现有 API；严格验证枚举、字段及证据 ID；不会改变原裁决 |
| 网关 | Pi 只拿本地代理凭据，真实上游密钥留在守护进程。Responses/Chat Completions 流式代理已接通；请求计数及哈希与原生流核验 |
| MCP | 真实 stdio 子进程执行 initialize / tools/list / tools/call；描述与返回保留 MCP 来源，真实调用需绑定已批准参数。当前为配置固定的只读服务，非任意第三方 MCP 产品 |
| 溯源 | SQLite nodes/edges/steps 可还原来源、候选、调用、返回、父子观察和慢镜关联；图无环核查已执行。`/trace` 为带截断标志的基础查询，前端和大图分页/按调用精选仍待建设 |
| 协议一致性 | event_id 内容不可重用篡改、producer_seq 缺口检测、call_id 参数及主体绑定、执行许可一次消费、未决 ASK 共享会话挂起 |

原始证据只在忽略的运行目录；真实 API key 不落运行证据。合成实验凭据可在本地原文与 collector 中出现，安全分量、模型输入和云端取证包不应含其明文，验真脚本逐轮检查。

## 验证与机制贡献

前两轮完整矩阵分别为 `matrix-20261016-132932` 与 `matrix-20261016-133812`：两轮均为正常关/开防护完成摘要；攻击关防护收到 56 字节合成凭据；攻击开防护在读取 `.env` 前 ASK、0 字节。第二轮原文 Token 位置采用官方 tokenizer，另有图关系与严格慢镜输出校验。

`verify_v2.py` 从原生 Pi JSONL、插件事件、SQLite、快镜输入哈希及 collector 独立核对。ASK 后尚未到达执行前 Hook 的候选调用单列为取消，不能错误地算成漏采，也不能算成已执行。前两轮完整证据见 `v2-first-validation.json`、`v2-validation.json`。

真实子 Agent 测试 `20261016-134302-27a57e`：父子会话经同一网关、权限边界保持共享、最终任务完成，14 项证据检查通过。第一次子任务超过现有 90 秒上限，Pi 自主再次派发后成功，失败原样保留；不能称为零错误运行。父任务耗时约 232 秒，性能显然仍需优化。

一个关键真实输出：在未授权读取 `.env` 时，Laya 的 action_alignment 为 expected（answer probability 0.8882），taint_followed 为 0.9807，内容性质为 uncertain。原版确实给出了跟随不可信指令的信号，但对授权对齐判断存在冲突。因此新增显式冲突 ASK 路径。单个样本无法证明三头概率可靠，也不能证明没有 D1 时此攻击就会漏过；确定性授权规则本身也会 ASK。慢镜返回的 ALIGNED/ASK 也只是模型评估，不能提升为已证明攻击因果。

原版 Laya CPU 的短输入冒烟测试约 0.84 秒；实际安全视图推理约 2–6 秒，明显没有达到毫秒级低开销目标。服务启动约 16–18 秒，单独列出，不混入 Agent 持续运行时间。慢镜在后台运行，结束后的证据等待也单独记录。不能只凭本地裁决比例就宣称“95% 性能达标”。

## 尚未完成的验收

1. D1 三头融合的独立保留集校准、误报/漏报测量，以及 CPU 推理开销优化。当前不宜转向扩库和前端包装。
2. 超出已覆盖规则的自然语言、间接数据流、代码内容、混淆与泛化语义压缩；不能把当前启发式实体提取包装成完整理解。
3. 大规模风险索引的查询成本、网关长请求 DLP 成本与内存预算压力验证。热视图有界不代表磁盘索引或所有临时缓冲恒定。
4. 通用远端 MCP、HTTP MCP、多层子 Agent、跨会话记忆、审批恢复、完整 OS 隔离和外部互联网边界。`/approve` 明确返回 501，避免假装恢复已实现。
5. 前端、完整大图查询、审计库加密/访问隔离及真正企业接入。当前只是本机受控实验环境。
