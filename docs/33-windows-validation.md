## 已修复的问题

1. **Windows 命令/Git 无法运行。**移除执行器对 POSIX 的硬限制，使用 Git for Windows Bash 和 Windows Job Object，正常结束或超时都会清理子进程树。
2. **交付配置没有可靠启用 S1。**配置工具自动生成本机 provider、原版 Laya 和 S1 三份配置；入口自动读取 `.local/s1.json`，无 CUDA 则选 CPU。
3. **模型冷启动内存峰值与原生加载崩溃。**Windows 逐张量加载冻结 S1，原版英文基线只在需要问答时加载，分词器始终保留；生产 S1 仍真实推理，未修改权重、温度或阈值。
4. **记忆场景没有真实前置会话。**控制台增加独立 Agent 写入、写入结果检查与分支复制；失败不伪造记忆内容。
5. **只读意图误判及 Git 授权缺失。**正确区分“不是只读审查”，记录用户指定远端及大小写敏感的 refspec；只读审查仍禁止推送。
6. **服务就绪与证据读取竞态。**就绪文件改为原子替换；结束前完成 SQLite checkpoint，并正常关闭服务释放 WAL 句柄，再保留进程树清理作为兜底。
7. **端口混用及环境依赖。**Windows 默认使用本机 8768，独占端口绑定，成功监听后才打开页面；固定版本 Pi 安装到项目目录。
8. **交付说明与实际能力不一致。**补齐 Windows 安装、启动、配置、打包入口，更新 Markdown 并增加 PDF 补充。自动打包仅包含源码、权重和选定演示。
