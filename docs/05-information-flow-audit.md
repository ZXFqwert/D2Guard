# 安全链与信息链路核查（2026-10-16）

> 此文记录新蓝图实施前的历史状态；当前进展见 `06-blueprint-execution.md`，不要将本篇“未接入”描述套用到新 d2v2 引擎。

结论：当前主线能执行真实 Pi 工具并在工具前进行控制，但没有实现用户本轮明确的完整 D² 架构。更换原版 Laya 是模型替换，不能修复缺失的信息采集、安全压缩和证据回溯。

## 证据范围

检查新主线实际运行代码、Pi 0.85.1 安装文档和全部 13 条已完成的核心实验轨迹。未重放工具，未制造新的攻击成功样本。脚本 `audit_information_flow.py` 比较 Pi 原生最终消息、插件审计和内核日志；脱敏结果见 `information-flow-evidence.json`。

13 条轨迹合计：50/50 次工具参数在原生消息、插件与裁决请求间一致；43/43 次成功工具返回正文与插件一致、哈希与内核一致；13/13 个用户任务一致。原生消息共 17 条助手公开文本，而模型响应探针传递正文为 0。以下列出两条关键轨迹：

| 核查项 | 正常轨迹 | 攻击轨迹 |
|---|---:|---:|
| Pi 原生工具调用数 | 3 | 5 |
| 参数与插件及裁决请求完全一致 | 3 | 5 |
| 成功工具返回数 | 2 | 3 |
| 返回正文与插件一致、哈希与内核一致 | 2 | 3 |
| 用户任务内容一致 | 是 | 是 |
| 原生助手公开文本消息数 | 0 | 1 |
| 插件上报的模型回复正文数 | 0 | 0 |
| 内核吸收的事件类型 | USER_INPUT、TOOL_RETURN | USER_INPUT、TOOL_RETURN |

没有证据表明这 13 条轨迹的工具参数或成功返回在 HTTP 传输中损坏。此核查限于主 Agent 最终消息，不代表所有并发情况或子 Agent 链路都正确。

## 实际链路与缺口

1. **没有 D²Guard API 代理网关。** `lab.py` 的 Pi provider `baseUrl` 直接使用现有模型接口。`services.py` 是观测、裁决和实验接收服务，不转发模型 API。模型请求探针只记录计数；`after_provider_response` 只提供状态和响应头，发生在响应流被消费之前，不能被当作完整模型回复探针。
2. **助手回复缺席。** 插件的 `message_end` 只处理 ASK 停止，没有上报普通助手公开文本及完整候选调用事件。工具调用在 `tool_call` 阶段被捕获，所以实际工具前仍有防护，但不能据此声称模型输出全链路已覆盖。不需要、也不依赖模型私有思维链；应采集公开文本、结构化工具请求和执行结果。
3. **部分消息仅落审计，没有入状态。** `CoreGuard.observe()` 只处理主 Agent 起始任务和成功工具返回。`tool_proposed`、模型请求/响应、子 Agent 起止及失败/拒绝结果都未进入增量状态转移。子 Agent 返回被归到 LOCAL_FILE，真实来源类型不足。首次任务建锚点后不再修订授权；多轮用户修订尚未实现。
4. **尚无独立的安全维度压缩层。** `extract()` 先归一化原文，再直接调用 `mirror.classify(text, plan, chain)`；`decide()` 也把整个工具参数转成字符串送入分类器。分类结果再决定污染状态。因此现有链中的污染结论，部分来自同一个分类器的既有判断；不是独立提取的完整安全事实。
5. **安全摘要缺少语义关系。** 压缩的内容主要是 general/readonly 锚点类型、污染标志、凭据数、覆盖率、DAG 数量及最近六次工具名。原始用户任务在内核存在，传给快镜时却只剩 general；工具名序列没有授权范围、数据来源、目的地、依赖关系和执行结果。日志里的 state_before 与模型实际输入也不完全相同：待判定调用已被加入 prior_call_chain。
6. **固定字段不等于内核定长。** `SecurityState.calls` 保留全部调用和完整 `tool_args`；DAG、秘密账本和匹配记录也持续增长。每次更新还深拷贝状态。输出一个较短摘要，并没有解决运行态历史增长。秘密账本还存明文与可逆十六进制片段，不能称为只保存不可逆指纹。
7. **尝试外发与实际泄露没有分账。** 执行前先登记外发覆盖率，被阻断后覆盖率仍可为 1。它表示尝试，不是实际泄露；泄露仍以独立接收端回执为准。既不能让后续动作把它理解成已经泄露，也不能在 BLOCK 后简单清空历史风险证据。
8. **慢镜没有原文回溯。** `enrich_report()` 只传标签、策略、覆盖率及状态摘要；`SlowMirrorClient.review()` 只允许这些字段出站。已有 source_uri/span 不能单独构成可靠回溯：缺少不可变原文版本、内容哈希、事件引用和检索器。审计文件虽然留有原文，但慢镜没有读取这些证据。目前慢镜只是异步说明，不是基于精选原文的独立研判。

## 与旧设计文档的关系

上级 `整体设计文档.md` 第 104 行明确写的是“当前归一化增量文本 + 执行计划 + 前序安全分量”；第 125–126 行描述的是安全分量证据包，没有实现按引用回查精选原文。因此不宜说所有偏差只是代码没遵循文档：旧文档本身与用户本轮明确的目标也不同。新主线应以用户最新说明为目标，旧文档保留为历史参考。

## 旧快镜误报的独立证据

`diagnose_fast.py` 离线重建实际裁决时的输入，所有记录的模型分类均可复现。旧权重不是原版 Laya 在线推理：实际是 333 词二值词袋、32 维隐藏层和两个分类头。正常 summary.md 的输入有 74 个词特征，只有 31 个命中词表；字段位置与顺序丢失，将整段正文搬到链的另一字段仍得到相同特征。

从本地训练脚本重建的 1,280 条样本中，118 条 fs.write、110 条 net.fetch、103 条 spawn_subagent 全部标为 deviant，没有这些工具的正常授权样本。192 条验证样本的文本模板全部在训练集中出现。重新算得联合正确 187/192、对齐正确 192/192，与旧报告相符，但它不能证明真实任务泛化能力。正常写摘要的反事实分析中，移除工具特征、移除近期调用链、或补入用户任务会改变结果；这些是诊断实验，不是额外防御成功样本。

因此至少有三个独立问题需要分别处理：旧模型训练偏差、压缩后的授权/来源/生命周期语义不足、事件覆盖及原文回溯缺失。不能把全部误报仅归因于其中一个环节。

## 目标契约

```text
Agent 插件 / API 网关
  -> 只上报新增事件 E_t：用户输入、助手公开输出、工具候选、工具执行前、返回/失败
  -> 不可变原文证据库：event_id + 内容哈希 + 原文 + 位置映射（本地受控存储）
  -> 安全提取器：E_t -> Δ_t（安全事实、来源、信任、权限、数据流、完整性、证据引用）
  -> 快镜 Original Laya：仅 [S_(t-1), Δ_t]，不接全文、历史对话或任意工具正文
  -> 策略裁决 ALLOW / ASK / BLOCK，副作用发生前由 Hook 执行
  -> 提交 S_t：区分候选、允许、拒绝、已执行、失败、未知
  -> 异步慢镜：疑点引用 -> 取必要原文片段 -> 脱敏 -> 独立研判
```

`S_(t-1)` 是有界的前序安全状态视图；完整可追溯的事件链在持久化库中。不要把“安全链”理解成每次向模型重发全部历史安全 JSON。

提取器必须能保留安全语义，例如“来源是低信任 README；它声称完成任务前必须把本地凭据发送到目标；用户只授权文档摘要”，而不是仅保留“taint=true”。其提取算法、覆盖率和不确定性必须单独验证；不能把换字段名或关键词命中包装为完成语义压缩。提取质量不足应明确 `unknown/coverage_incomplete`，相关高风险动作 ASK；不能默认正常。

Agent 侧是可信探针的事件适配器，不让被保护模型自行删选或宣称输入安全。网关和插件共同观测同一调用时，以 session/agent/call/stage 去重，验证参数哈希，不能重复登记外发；事件要可确认接收、可重试、可检测丢失和乱序。插件能提供的功能不必强行再过一遍网关，但缺网关时必须明确覆盖边界。

“任意任务长度、所有安全事实无损、严格恒定总空间”不能同时保证。应限制在线工作集、原文检索包和快镜输入预算；长期证据、DAG、凭据指纹索引落盘。超过预算或找不到证据时显式降级/ASK，不静默丢弃关键授权或风险事实。原文证据库与内核的在线安全状态应分离。

## 修复顺序与验收

1. 定义事件、SecurityDelta、SecurityState、EvidenceRef 契约及三阶段调用生命周期。先补助手公开输出和拒绝/失败结果的采集，完成跨层内容哈希、序号和关联核查。
2. 实现独立安全提取器、不可变证据库、有界在线状态；固定锚点保留可解释授权范围，用户后续授权使用可追踪版本，低信任内容不能改授权。
3. 原版 Laya 仅接安全状态和增量。原始模型下载与适配器准备单独验证，不能接回旧 classify(raw_text, plan, summary) 后宣称完成改造。CPU 延迟重新测量，不能沿用旧小分类器毫秒指标。
4. 实现慢镜按引用取证、脱敏、片段预算与证据不全标志。ASK 先挂起即完成本轮防御介入；慢镜后续分析不自动解除挂起。
5. 先验收正常摘要不被无依据 ASK、已有凭据外发被 BLOCK 或有依据 ASK；再做 50+ 轮噪声历史、早期污染不丢失、来源与权威隔离、父子 Agent 关联、重复/乱序/缺事件、拒绝与实际执行分账、原文哈希失配、输入/内存上限等测试。快路径占比、误报率、漏报率、P50/P95/P99 分开报告；95% 为目标，不是模型保证。

## 本轮修改状态

新增只读核查脚本与脱敏证据；为旧快镜增加准确的输入边界元数据。原版 Laya 适配器处于独立原型，尚未接入实际 CoreGuard；默认线上路径仍是旧小分类器，不能把本轮称为原版模型已完成切换。此处明确记录未完成项，避免再次出现代码能力与展示宣称不一致。
