# 直接输入、原生会话与交付复核（2026-10-20）

本机启动控制台后，自由对话入口为 `http://127.0.0.1:8768/#/chat`，攻防竞技场为 `#/arena`；部署端另可维护等价的公开预览入口（其地址由部署端提供，不写入交付件）。前端连接 Pi 0.85.1 原生 RPC，会话上下文、压缩与工具循环由 Pi 管理；D²Guard 执行输入检测、工具裁决、审批和证据记录。批量配对仍使用真实 Pi CLI，不含重放或脚本伪造的动作。

## 运行与延迟

已修正支持 Responses 思考控制的模型能力声明，使 Pi 的 `--thinking off` 显式发送 `reasoning.effort=none`。对不支持该参数的接口，默认不启用此能力声明。历史默认思考与修正后的结果分开报告。

快镜与分词器在控制台启动时常驻，独立会话状态保持隔离。Windows 采用经原权重转换值核对的只读 FP32 映射，解决页面文件不足时的权重加载失败。没有调整权重、温度或判定阈值。两端最终四轮会话的防护服务启动分别为 GPU 0.603 s、CPU 1.375 s，首条回复分别为 2.527 s、4.742 s；这些是单次部署观测，不含模型首次加载。慢镜归档单独计时，后台归档不占用新会话的执行入口。
