💡 什么是「调用来源拓扑图 (Provenance DAG)」？图中的方块代表什么？
1. 长条小绿方块：代表智能体执行的正常合规原子操作（如读取任务说明、查询合规代码）。由于执行过程在主任务上下文内没有产生跨域污染，形成了一条平稳的连续安全链。
2. 橙色方块：代表外部输入污染点 (Tainted Input)，例如从外部网页或第三方材料中解析出潜在二阶注入载荷。
3. 红色高亮方块：代表 D²Guard 安全内核在此处果断下刀阻断（BLOCK）！说明攻击者试图利用前面获取的敏感凭据进行跨域外发或覆写文件，被安全不变式合约当场熔断，保护了沙箱！
4. 点击任意节点：可在右侧面板中回溯原始 HTTP 报文、沙箱调用参数、脱敏核验证据与真实耗时。
